§01O que é

Não é um fork. Nada foi redesenhado.

01

A Noctua Iosevka é uma seleção cuidadosa entre as variantes de glifo que a Iosevka já oferece, mais uma escada de larguras remapeada. A largura Normal tem 600 unidades — o mesmo avanço de 0,6 em da JetBrains Mono — e assim cada glifo tem espaço para ser ele mesmo.

spacing = "term"

Os símbolos são estreitados até caber na célula do terminal, e as ligaduras continuam no arquivo como um recurso OpenType opcional, que cada aplicativo pode desligar.

noCvSs = false

As variantes de caractere e os conjuntos estilísticos vão junto no arquivo, então qualquer editor que entenda OpenType troca formas enquanto você trabalha.

exportGlyphNames = true

Os nomes dos glifos ficam no arquivo — é deles que dependem o patcher da Nerd Fonts e terminais como o kitty.

§04Três inclinações

Reta, oblíqua, itálica.Reta, oblíqua, itálica.

04

Os dois estilos inclinados pendem 9°. A oblíqua é a romana inclinada. A itálica tem a mesma inclinação, com letras cursivas onde faz diferença. Ela redesenha, entre outras, C c e i t e ß æ œ ſ no latim, ε ι τ ϲ no grego e, no cirílico, as maiúsculas С Є e a maior parte das minúsculas — а в г д е и й п с т у ф ц ш щ ъ ы ь. As letras acentuadas acompanham a letra-base, e alguns símbolos, como ¢ © €, também mudam. Ao todo, 466 dos 7.580 pontos de código são diferentes; o resto é compartilhado com a oblíqua.

§05Legibilidade

Toda letra parecida, resolvida pela forma.Toda letra parecidaparecida, resolvida pela forma.

05

il1I|0O8B5SZ23 5 Sg q 9

O conjunto de aceitação: em qualquer tamanho e nas três inclinações, nenhum destes caracteres pode ser confundido com o vizinho. Abaixo, cada par é impresso duas vezes no mesmo lugar, em duas tintas — onde as cores se separam, as letras são diferentes.

  • 0O0 · OZero oval com um traço comprido por dentro; nunca se confunde com Ø ou ∅.
  • 1l1 · lO um tem serifa no alto e no pé; o l termina numa cauda reta.
  • IlI · lUm I maiúsculo com serifas contra o l de cauda.
  • l|l · |A barra continua barra: sem serifa e sem cauda.
  • Z2Z · 2O Z leva um traço horizontal no meio.
  • 5S5 · SUm cinco de topo reto contra um S com uma serifa só.
  • 8B8 · BUm oito cruzado contra um B com serifas dos dois lados.
  • QOQ · OA cauda do Q atravessa o bojo e se enrola para fora.
  • g9g · 9Um g de um andar só, com gancho reto, contra o nove redondo.
  • rnmrn · mO m tem cauda, então r n nunca vira m.

§07Variantes de caractere

99 botões, um glifo de cada vez.

07

Abaixo dos conjuntos estilísticos ficam as variantes de caractere, de cv01 a cv99: um recurso por letra, e cada valor escolhe uma das formas dela. As contagens vêm da própria fonte. Um dos valores sempre reproduz o glifo padrão, então “33 formas” quer dizer 33 contornos diferentes, contando o padrão.

    // Converte uma cor hexadecimal como "#0b0a10" nos seus três canais.
use std::num::ParseIntError;

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Rgb { pub r: u8, pub g: u8, pub b: u8 }

impl std::str::FromStr for Rgb {
    type Err = ParseIntError;

    /// Falha com qualquer coisa que não tenha dois dígitos hexadecimais por canal.
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        let hex = s.trim_start_matches('#');
        let byte = |i: usize| u8::from_str_radix(&hex[i..i + 2], 16);
        Ok(Rgb { r: byte(0)?, g: byte(2)?, b: byte(4)? })
    }
}

    debounce.ts TypeScript

    /** Executa `fn` quando as chamadas param por `ms` milissegundos. */
export function debounce<T extends unknown[]>(fn: (...args: T) => void, ms = 120) {
  let timer: ReturnType<typeof setTimeout> | undefined;
  return (...args: T): void => {
    if (timer !== undefined) clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  };
}

// Registra o tamanho da janela no máximo uma vez por rajada de redimensionamentos.
const onResize = debounce(() => console.log(`${innerWidth}×${innerHeight}`));
window.addEventListener("resize", onResize, { passive: true });

    # Conta os caracteres que se confundem num arquivo — uma pequena auditoria de legibilidade.
from collections import Counter
from pathlib import Path

CONFUSABLE = set("il1I|0O8B5SZ2gq9")

def audit(path: Path) -> dict[str, int]:
    text = path.read_text(encoding="utf-8")
    counts = Counter(ch for ch in text if ch in CONFUSABLE)
    return {ch: n for ch, n in counts.most_common() if n >= 1}

if __name__ == "__main__":
    for ch, n in audit(Path("README.md")).items():
        print(f"{ch!r:>5} → {n:>4}")

    -- | A escada de larguras da Noctua Iosevka, em unidades por em.
module Ladder where

data Width = Condensed | SemiCondensed | Normal | SemiExtended | Extended
  deriving (Show, Eq, Ord, Enum, Bounded)

advance :: Width -> Int
advance w = case w of
  Condensed     -> 456
  SemiCondensed -> 548
  Normal        -> 600
  SemiExtended  -> 658
  Extended      -> 720

-- Cada largura como fração do em.
ladder :: [(Width, Double)]
ladder = [ (w, fromIntegral (advance w) / 1000) | w <- [minBound .. maxBound] ]

    §13Para baixar

    Baixar e instalar.

    13

    A versão v1.0.0 traz um arquivo compactado por largura e formato, cada um com as licenças dentro. Comece pela Normal; para o terminal, pegue a versão Nerd Font.

    • Normal600 · comece por aqui

    • Condensed456

    • SemiCondensed548

    • SemiExtended658

    • Extended720

    Linux

    1. Descompacte o arquivo na sua pasta de fontes — sem precisar de root.

      mkdir -p ~/.local/share/fonts/NoctuaIosevkaunzip noctua-iosevka-nerd-font-ttf-normal.zip -d ~/.local/share/fonts/NoctuaIosevka

    2. Atualize o cache de fontes e confira o nome exato da família.

      fc-cache -ffc-match "NoctuaIosevka Nerd Font Mono"

    3. No NixOS ou no Guix, aponte o gerenciador de pacotes para os arquivos em vez de copiá-los para o $HOME: a cópia funciona, mas some na próxima recompilação que limpar o perfil.

    macOS

    1. Descompacte o arquivo que você baixou.

    2. Abra os arquivos .ttf no Catálogo de Fontes, ou coloque-os em ~/Library/Fonts/:

      unzip noctua-iosevka-nerd-font-ttf-normal.zip -d ~/Library/Fonts/NoctuaIosevka

    3. Feche o terminal ou o editor por completo e abra de novo.

    Windows

    1. Descompacte o arquivo que você baixou.

    2. Selecione todos os arquivos .ttf, clique com o botão direito e escolha Instalar para todos os usuários (ou Instalar).

    3. Reinicie o aplicativo: muitos programas só procuram fontes quando abrem.

    Depois, configure o seu terminal ou editor:

    Ghostty ~/.config/ghostty/config

    font-family = "NoctuaIosevka Nerd Font Mono"

    kitty ~/.config/kitty/kitty.conf

    font_family NoctuaIosevka Nerd Font Mono

    Alacritty ~/.config/alacritty/alacritty.toml

    [font.normal]family = "NoctuaIosevka Nerd Font Mono"

    VS Code settings.json

    "editor.fontFamily": "'NoctuaIosevka Nerd Font Mono', monospace","editor.fontLigatures": true,"terminal.integrated.fontFamily": "'NoctuaIosevka Nerd Font Mono'"

    Emacs init.el

    (add-to-list 'default-frame-alist '(font . "NoctuaIosevka Nerd Font Mono-13"))

    Vale para todas as janelas, inclusive as que o emacsclient abre. No terminal, o emacs -nw usa a fonte do terminal.

    Neovim init.lua

    vim.o.guifont = "NoctuaIosevka Nerd Font Mono:h13"

    Para uma interface gráfica como o Neovide. No terminal, o Neovim usa a fonte do terminal: configure-a acima.

    Se a fonte não aparecer, confirme que o processo terminou mesmo — aplicativos de instância única continuam vivos com todas as janelas fechadas — antes de desconfiar de qualquer outra coisa.
