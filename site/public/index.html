§01What it is

Not a fork. Nothing redrawn.

01

Noctua Iosevka is a deliberate selection among the glyph variants Iosevka already offers, plus a remapped width ladder. Its Normal width is 600 units — the same 0.6 em advance as JetBrains Mono — so every glyph has room to be itself.

spacing = "term"

Symbols are narrowed to the terminal cell, and the ligatures stay in the file as an optional OpenType feature that each application can switch off.

noCvSs = false

The character variants and the stylistic sets are exported, so any OpenType-aware editor can swap shapes while you work.

exportGlyphNames = true

Glyph names survive in the file — what the Nerd Fonts patcher, and terminals such as kitty, rely on.

§04Three slopes

Upright, oblique, italic.Upright, oblique, italic.

04

Both slanted faces lean 9°. The oblique is the roman, slanted. The italic is the same slant with cursive letters where it counts. It redraws, among others, C c e i t and ß æ œ ſ in Latin, ε ι τ ϲ in Greek, and in Cyrillic the capitals С Є and most of the lowercase — а в г д е и й п с т у ф ц ш щ ъ ы ь. Accented letters follow their base letter, and some symbols, such as ¢ © €, change too. In all, 466 of the 7,580 code points differ; the rest are shared with the oblique.

The acceptance set: at any size and in all three slopes, no character here may be mistaken for its neighbour. Below, each pair is printed twice on the same spot, in two inks — wherever the colours separate, the letters differ.

  • 0O0 · OOval zero with a long dot inside; it never meets Ø or ∅.
  • 1l1 · lThe one has serifs at the top and the foot; the l ends in a flat tail.
  • IlI · lA serifed capital I against the tailed l.
  • l|l · |The bar stays a bar: no serif, no tail.
  • Z2Z · 2The Z carries a horizontal crossbar.
  • 5S5 · SA flat-topped five against an S with one serif.
  • 8B8 · BA crossing eight against a B with serifs on both sides.
  • QOQ · OThe Q’s tail crosses the bowl and curls away.
  • g9g · 9A single-storey g with a flat hook against the round nine.
  • rnmrn · mThe m carries a tail, so r n never reads as m.

99 dials, one glyph at a time.

    ladder.rs Rust

    // Parse a hex colour such as "#0b0a10" into its three channels.
use std::num::ParseIntError;

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Rgb { pub r: u8, pub g: u8, pub b: u8 }

impl std::str::FromStr for Rgb {
    type Err = ParseIntError;

    /// Fails on anything that is not two hex digits per channel.
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        let hex = s.trim_start_matches('#');
        let byte = |i: usize| u8::from_str_radix(&hex[i..i + 2], 16);
        Ok(Rgb { r: byte(0)?, g: byte(2)?, b: byte(4)? })
    }
}

    debounce.ts TypeScript

    /** Run `fn` once the calls have stopped for `ms` milliseconds. */
export function debounce<T extends unknown[]>(fn: (...args: T) => void, ms = 120) {
  let timer: ReturnType<typeof setTimeout> | undefined;
  return (...args: T): void => {
    if (timer !== undefined) clearTimeout(timer);
    timer = setTimeout(() => fn(...args), ms);
  };
}

// Log the window size at most once per burst of resizes.
const onResize = debounce(() => console.log(`${innerWidth}×${innerHeight}`));
window.addEventListener("resize", onResize, { passive: true });

    audit.py Python

    # Count the confusable characters in a file — a tiny legibility audit.
from collections import Counter
from pathlib import Path

CONFUSABLE = set("il1I|0O8B5SZ2gq9")

def audit(path: Path) -> dict[str, int]:
    text = path.read_text(encoding="utf-8")
    counts = Counter(ch for ch in text if ch in CONFUSABLE)
    return {ch: n for ch, n in counts.most_common() if n >= 1}

if __name__ == "__main__":
    for ch, n in audit(Path("README.md")).items():
        print(f"{ch!r:>5} → {n:>4}")

    tail.go Go

    // tail follows a file the way `tail -f` does, line by line.
package main

import ("bufio"; "fmt"; "os"; "time")

func main() {
	f, err := os.Open("/var/log/syslog")
	if err != nil {
		fmt.Fprintln(os.Stderr, "tail:", err)
		os.Exit(1)
	}
	r := bufio.NewReader(f)
	for {
		line, err := r.ReadString('\n')
		if err != nil { time.Sleep(250 * time.Millisecond); continue } // nothing new yet
		fmt.Print(line)
	}
}

    Ladder.hs Haskell

    -- | The width ladder of Noctua Iosevka, in units per em.
module Ladder where

data Width = Condensed | SemiCondensed | Normal | SemiExtended | Extended
  deriving (Show, Eq, Ord, Enum, Bounded)

advance :: Width -> Int
advance w = case w of
  Condensed     -> 456
  SemiCondensed -> 548
  Normal        -> 600
  SemiExtended  -> 658
  Extended      -> 720

-- Each width as a fraction of the em.
ladder :: [(Width, Double)]
ladder = [ (w, fromIntegral (advance w) / 1000) | w <- [minBound .. maxBound] ]

    §13Get it

    Download & install.

    13

    Release v1.0.0 ships one archive per width and format, each with its licences inside. Start with Normal; for the terminal, take the Nerd Font build.

    Linux

    1. Unpack the archive into your own font folder — no root needed.

      mkdir -p ~/.local/share/fonts/NoctuaIosevkaunzip noctua-iosevka-nerd-font-ttf-normal.zip -d ~/.local/share/fonts/NoctuaIosevka

    2. Refresh the font cache, then confirm the exact family name.

      fc-cache -ffc-match "NoctuaIosevka Nerd Font Mono"

    3. On NixOS or Guix, point the package manager at the files instead of copying them into $HOME: a copy works, but the next rebuild that prunes the profile takes it away.

    macOS

    1. Unzip the archive you downloaded.

    2. Open the .ttf files with Font Book, or put them in ~/Library/Fonts/:

      unzip noctua-iosevka-nerd-font-ttf-normal.zip -d ~/Library/Fonts/NoctuaIosevka

    3. Quit and reopen your terminal or editor completely.

    Windows

    1. Unzip the archive you downloaded.

    2. Select every .ttf file, right-click and choose Install for all users (or Install).

    3. Restart the application: many programs look for fonts only when they start.

    Then tell your terminal or editor:

    Ghostty ~/.config/ghostty/config

    font-family = "NoctuaIosevka Nerd Font Mono"

    kitty ~/.config/kitty/kitty.conf

    font_family NoctuaIosevka Nerd Font Mono

    Alacritty ~/.config/alacritty/alacritty.toml

    [font.normal]family = "NoctuaIosevka Nerd Font Mono"

    VS Code settings.json

    "editor.fontFamily": "'NoctuaIosevka Nerd Font Mono', monospace","editor.fontLigatures": true,"terminal.integrated.fontFamily": "'NoctuaIosevka Nerd Font Mono'"

    Emacs init.el

    (add-to-list 'default-frame-alist '(font . "NoctuaIosevka Nerd Font Mono-13"))

    Every frame takes it, the ones emacsclient opens included. In a terminal, emacs -nw draws with the terminal’s font.

    Neovim init.lua

    vim.o.guifont = "NoctuaIosevka Nerd Font Mono:h13"

    For a graphical front end such as Neovide. In a terminal, Neovim draws with the terminal’s font: set that one above.

    If the font does not show up, make sure the process really ended — single-instance apps stay alive with every window closed — before suspecting anything else.
